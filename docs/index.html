📊 Option 1: Local Dashboard (Recommended)

Run the monitoring stack locally on your machine for maximum privacy and control.

Quick Start:

# Clone the repository git clone https://github.com/Devon-ODell/EleanorPlatform.git cd EleanorPlatform # Start monitoring stack (Prometheus + Grafana + Bot) docker-compose -f docker-compose.monitoring.yml up -d # Access dashboards: # Grafana: http://localhost:3000 (admin/eleanor2025) # Prometheus: http://localhost:9090 # Metrics: http://localhost:8000/metrics

☁️ Option 2: Grafana Cloud (Public)

Publish your dashboard to Grafana Cloud for remote access. Configure authentication and sharing settings.

⚠️ Privacy Warning: Public dashboards may expose trading metrics. Use authentication and consider data sensitivity.

Steps:

  1. Sign up for Grafana Cloud (Free tier available)
  2. Create a new stack
  3. Configure Prometheus remote write endpoint
  4. Import dashboard JSON from monitoring/grafana/dashboards/eleanor_arbitrage.json
  5. Set up authentication (API keys, viewer permissions)
  6. Share dashboard URL securely

🔒 Option 3: Self-Hosted with Cloudflare Tunnel

Expose your local Grafana securely to the internet using Cloudflare Tunnel (zero trust).

Setup:

# Install cloudflared wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb sudo dpkg -i cloudflared-linux-amd64.deb # Authenticate with Cloudflare cloudflared tunnel login # Create tunnel cloudflared tunnel create eleanor-dashboard # Run tunnel cloudflared tunnel --url http://localhost:3000
✅ Benefits: No port forwarding, free SSL, Cloudflare Access for authentication

🛠️ Local Setup Instructions

Prerequisites:

  • Docker & Docker Compose installed
  • Git installed
  • 4GB+ RAM available

Step 1: Clone & Start

git clone https://github.com/Devon-ODell/EleanorPlatform.git cd EleanorPlatform docker-compose -f docker-compose.monitoring.yml up -d

Step 2: Access Grafana

Open http://localhost:3000 in your browser

  • Username: admin
  • Password: eleanor2025 (change this!)

Step 3: View Dashboard

The "Eleanor Platform - DeFi Arbitrage" dashboard is pre-configured and ready.

Step 4: Security Hardening (Important!)

# Create .env file cp .env.example .env # Edit .env and set strong passwords nano .env # Restart with new credentials docker-compose -f docker-compose.monitoring.yml down docker-compose -f docker-compose.monitoring.yml up -d
⚠️ Security Reminder: Always change default passwords! Keep metrics endpoint (port 8000) firewalled.
